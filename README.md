# บิลค่าเช่าตลาด — LIFF App (พิมพ์ A5)

เว็บแอปไฟล์เดียว (`index.html`) สำหรับออก **ใบแจ้งหนี้/ใบเสร็จค่าเช่าแผงตลาดรายเดือน**
กรอกเลขมิเตอร์ → คิดค่าน้ำค่าไฟ + ค่าเช่า + ค้างจ่าย + ค่าปรับ ให้อัตโนมัติ →
กด **พิมพ์บิลทั้งหมด (A5)** ปริ้นลงกระดาษ A5 ได้ทันที หรือบันทึกเป็น PDF

ข้อมูลทั้งหมดเก็บใน **เครื่อง (localStorage)** — ไม่มีเซิร์ฟเวอร์ ไม่ต่อ Google

---

## สูตรที่ใช้ (ตรงกับไฟล์ Excel เดิม)

| รายการ | วิธีคิด |
|---|---|
| ค่าเช่ารายเดือน | ตามที่ตั้งไว้ต่อล็อก |
| ค่าไฟ | (เลขครั้งนี้ − เลขครั้งก่อน) × เรตค่าไฟ/หน่วย (ตั้งค่าเริ่มต้น 10) |
| ค่าน้ำ | (เลขครั้งนี้ − เลขครั้งก่อน) × เรตค่าน้ำ/หน่วย (ตั้งค่าเริ่มต้น 20) |
| ค้างจ่าย | กรอกเอง |
| ค่าปรับ | กรอกเอง หรือกดปุ่ม “คำนวณ” จากวันที่ชำระ = (วันชำระ − วันครบกำหนด) × ค่าปรับ/วัน |
| รวมทั้งสิ้น | ผลบวกทุกบรรทัด |

- **เลขครั้งก่อน** ดึงอัตโนมัติจาก “เลขครั้งนี้” ของเดือนก่อนหน้า (ขึ้นเป็นตัวจาง ๆ) แก้ทับได้
- **ผู้เช่าหลายล็อกรวมบิลใบเดียว** (เช่น A06-A09) — เพิ่มได้ในหน้า “ผู้เช่า” > เพิ่มล็อก
- **บรรทัดพิเศษ** เช่น “ค่าน้ำ (ตู้แดง)” — เพิ่มได้ในหน้าแก้ไขผู้เช่า
- เลขที่บิลออกให้อัตโนมัติ: `INV` + ปี ค.ศ. + เดือน + เลขล็อก เช่น `INV202609A01`

## 6 แท็บ

| แท็บ | ทำอะไร |
|---|---|
| **ออกบิล** | กรอกเลขมิเตอร์ครั้งนี้ของทุกแผง**ในหน้าเดียว** (ไม่ต้องคลิกเข้าทีละราย) เห็นยอดทันที → พิมพ์รายใบ 🖨 หรือ “พิมพ์บิลทั้งหมด (A5)” |
| **ค่าน้ำ–ไฟ** | ตารางมิเตอร์ทั้งหมด (ล็อก × เดือน) แบบเดียวกับชีต “รวมค่าน้ำค่าไฟ” — สลับดูค่าไฟ/ค่าน้ำ, โหมด “เลขมิเตอร์” (แก้ได้) หรือ “หน่วยที่ใช้”, แก้ตัวเลขบันทึกอัตโนมัติและไปคิดในบิลทันที |
| **ผู้เช่า** | เพิ่ม/แก้/ลบผู้เช่า, ค่าเช่าต่อล็อก, หลายล็อกรวมบิล, บรรทัดพิเศษ · ปุ่ม **โหลดข้อมูลจากไฟล์ Excel** = ผู้เช่า 23 ราย + มิเตอร์ย้อนหลัง 10 เดือน (ธ.ค. 68 – ก.ย. 69) |
| **เทมเพลตบิล** | แก้ข้อความ/ป้ายทุกจุดบนใบบิล (หัวบิล, หัวตาราง, ป้ายรายการ, ช่องลงชื่อ, เปิด/ปิดฟิลด์) มีตัวอย่าง A5 อัปเดตสด |
| **สรุป/ย้อนหลัง** | • *รายเดือน*: ตารางแจกแจงทุกแผง (ค่าเช่า/หน่วยไฟ/ค่าไฟ/หน่วยน้ำ/ค่าน้ำ/ค้าง/ปรับ/รวม) + แถวรวม — แตะแถวเพื่อพิมพ์บิลใบนั้นซ้ำ<br>• *ย้อนหลังหลายเดือน*: ตารางเทียบ 12 เดือน เลือกดู ยอดรวม / ค่าไฟ / ค่าน้ำ / หน่วยไฟ / หน่วยน้ำ / ค่าเช่า<br>• พิมพ์สรุป (A4 แนวนอน) · บันทึก CSV |
| **ตั้งค่า** | ชื่อตลาด, บัญชี, เรต, ค่าปรับ, หมายเหตุ, LIFF ID, สำรอง/นำเข้า/ล้างข้อมูล |

> เลขมิเตอร์ทุกเดือนถูกเก็บไว้หมด — ย้อนดู/แก้/พิมพ์บิลเดือนก่อน ๆ ได้ตลอด

## ข้อมูลที่ import มาจากไฟล์ Excel (ปุ่ม “โหลดข้อมูลจากไฟล์ Excel”)

- **ผู้เช่า** — อ้างอิง Tab *Invoice Detail*: โซน A รวมล็อกเป็นบิลเดียวตามจริง
  (ข้าวแกง = A02+A03, เจ้ยา = A06-A09, ร้าน 20 บาท = A10-A11, เจ้อร มีค่าน้ำตู้แดง = มิเตอร์ A19)
  + โซน B01–B09 และ C01 (ใส่เฉพาะค่าเช่า ยังไม่มีข้อมูลมิเตอร์ในไฟล์)
- **มิเตอร์** — อ้างอิง Tab *ค่าน้ำค่าไฟ*: เลขจดจริง ธ.ค. 2568 – ก.ย. 2569 ครบทุกล็อก
- **บิล** — ออกตามชื่อผู้เช่า แจกแจงรายล็อกเหมือน Tab *กันยายน* (รายเดือน A06 / ค่าไฟ A06 / ค่าน้ำ A06 …)
- **เรตค่าไฟ/น้ำ** ตั้งเป็น 10 / 20 บาท/หน่วย (ตามใบแจ้งหนี้จริงในไฟล์ ไม่ใช่ 7/15 ที่หัวชีต)

## เริ่มใช้งานเร็ว ๆ

1. เปิด `index.html` ในมือถือ/คอมได้เลย (เปิดไฟล์ตรง ๆ ก็ทำงาน)
2. แท็บ **ตั้งค่า** — ใส่ชื่อตลาด, เลขบัญชี, เรตค่าน้ำค่าไฟ, ข้อความหมายเหตุ
3. แท็บ **ผู้เช่า** — กด “โหลดตัวอย่าง 18 ราย” เพื่อลองเล่น หรือ “+ เพิ่มผู้เช่า” เอง
4. แท็บ **ออกบิล** — เลือกเดือน/ปี กรอกเลขมิเตอร์ครั้งนี้ → กดพิมพ์
5. หน้าปริ้น: กด **พิมพ์ / บันทึก PDF** (เบราว์เซอร์จะตั้งขนาด A5 ให้เอง)

> สำรองข้อมูลก่อนเปลี่ยนเครื่อง: ตั้งค่า > **ส่งออกไฟล์สำรอง** แล้วเก็บไฟล์ `.json` ไว้

## เอาขึ้น GitHub Pages (ใช้เป็น LIFF endpoint)

```bash
# ในโฟลเดอร์นี้
git init
git add index.html README.md
git commit -m "market rent billing LIFF app"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

- GitHub → repo → **Settings → Pages** → Source = `Deploy from a branch` → `main` / `root` → Save
- ได้ URL: `https://<username>.github.io/<repo>/`

## ตั้งค่า LIFF ใน LINE

1. [LINE Developers Console](https://developers.line.biz/console/) → สร้าง **Provider**
2. สร้าง **LINE Login channel** → แท็บ **LIFF** → **Add**
   - Endpoint URL: `https://<username>.github.io/<repo>/`
   - Size: `Full`
   - ไม่ต้องเปิด scope พิเศษ (แอปนี้ไม่ต้องล็อกอิน)
3. คัดลอก **LIFF ID** → เปิดแอป → แท็บ **ตั้งค่า** → ใส่ในช่อง “LIFF ID” → บันทึก
4. ลิงก์เปิดในไลน์: `https://liff.line.me/<LIFF_ID>`
   - เอาไปใส่ Rich menu / ปุ่มใน LINE OA ได้เลย

> แอปทำงานได้แม้ไม่ใส่ LIFF ID (โหมดเว็บปกติ) — LIFF ID มีไว้ให้เปิดลื่นในแอป LINE เท่านั้น

## หมายเหตุการพิมพ์

- **มือถือ:** กดพิมพ์แล้วเลือกเครื่องพิมพ์ หรือ “บันทึกเป็น PDF” แล้วส่งเข้าร้านปริ้น
- **คอม:** ในกล่อง Print ตั้ง Paper size = **A5**, Margins = Default, ปิด “Headers and footers”
- 1 ผู้เช่า = 1 หน้า A5 เสมอ (ขึ้นหน้าใหม่อัตโนมัติ)
